# Task: Per-trade max-$-at-risk hard cap (Qwen lesson)

## Description

Qwen 3 Max won Alpha Arena Season 1 with explicit per-trade $-at-risk limits (~$487 max loss on a $64K notional, ~5% exposure). Our existing gates cap position size as a percent of equity (`size_pct`) but never compute the actual dollar at risk on each trade.

Add a hard cap: `qty × |entry − stop|` must be ≤ 1% of portfolio equity. Independent of `size_pct` — they protect against different things.

## Acceptance Criteria

- [ ] New risk check `checkMaxDollarRisk` in `internal/risk/manager.go`.
- [ ] Inputs: `Quantity` (computed from `size_pct × portfolio_value / signal_price`), `SignalPrice`, `StopLoss`, `PortfolioValue`. Existing `CheckInput` likely needs `Quantity` added.
- [ ] Computes: `dollar_at_risk = qty × |signal_price − stop_loss|`, `max_allowed = max_dollar_risk_pct × portfolio_value / 100`.
- [ ] Block reason: `$-at-risk %.2f%% > limit %.2f%%` (both expressed as percent of portfolio).
- [ ] Config: new field `risk.max_dollar_risk_pct` (default `1.0`).
- [ ] Runs after `checkPositionSize`, before `checkMaxOpenPositions`.
- [ ] Unit tests: trade at exactly the cap passes; one cent over fails; zero stop-distance handled (already covered by `checkRiskReward` returning a fail before this check is reached).

## Technical Details

- `risk.CheckInput` currently has `SizePct` but not `Quantity`. Either compute quantity inline in the check, or thread it through. Inline is simpler:
  ```go
  qty := (in.SizePct/100) * in.PortfolioValue / in.SignalPrice
  dollarAtRisk := qty * math.Abs(in.SignalPrice - in.StopLoss)
  riskPct := dollarAtRisk / in.PortfolioValue * 100
  ```
- Edge case: if `PortfolioValue == 0`, pass (mirrors `checkDailyLossLimit`).
- Default 1% chosen because the typical recommendation in retail risk literature is 0.5–2%; 1% is the centre.
