# Task: Strike-selection gate engine

## Description

Implement the deterministic, fail-closed pipeline that turns "ORB fired on underlying X, direction D" into a chosen option contract. Pure logic in a new `internal/options` package, built against a chain-data interface (so it doesn't wait on Task 2's concrete client) and an IV-Rank provider interface (Task 4). This is the heart of the strategy's options layer.

## Acceptance Criteria
- [ ] Gate pipeline runs in order and **aborts the trade (fail-closed)** on any gate failure OR any uncomputable input:
  1. **IV-Rank gate**: proceed only if underlying IV Rank < ceiling (default 70%).
  2. **Expiry gate**: filter chain to `0 < DTE ≤ 5` (nearest weekly).
  3. **Delta gate**: pick the contract with delta in band (default 0.50–0.60); null delta → gate-fail.
  4. **Spread gate**: proceed only if `(ask-bid)/mid < ceiling` (default 5%).
- [ ] **Earnings-blackout gate** (single names only): abort if within the configured window around the underlying's scheduled earnings; ETFs (SPY/QQQ) exempt.
- [ ] Direction mapping: long breakout → call, short breakout → put.
- [ ] Every evaluation (pass and each abort) returns a structured result logging inputs + values + the deciding gate.
- [ ] All thresholds injected from config (Task 9) with safe defaults; no magic numbers.
- [ ] Fail-closed inversion is explicit and unit-tested (missing IV-Rank → abort, missing spread → abort, null delta → abort).
- [ ] Unit tests with numeric fixtures cover each gate pass/fail boundary and the full pipeline.

## Technical Details
- New package `internal/options` (shared with Task 4; coordinate package scaffolding — first task to land creates `doc.go`/package file).
- Consumes a `ChainProvider` interface (impl = Task 2) and an `IVRankProvider` interface (impl = Task 4); depend on interfaces, not concretes.
- Contrast the ORB entry-quality filters which FAIL OPEN (`#362`) — these risk gates FAIL CLOSED. Document the inversion at the call site.
- 0DTE greeks are intermittently null → the `DTE ≤ 5` bias plus null-delta-aborts handles it.
