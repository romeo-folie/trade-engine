# Task: Alpaca options adapter

# Description

Extend the Alpaca broker to trade equity options. Today `alpaca_broker.go` trades stocks only and ignores `SecType`. Add an options order path plus the data-side client the gate engine and IV pipeline consume. Reuse the existing HTTP `do`/auth plumbing; branch on `SecType=="OPT"` (IBKR's `secType` branching is the template).

The read-only **options data client** (chain snapshots + contract resolution) is self-contained and can be built first, in parallel, against fixtures — it's what Tasks 3 and 4 depend on. The order/position **integration** requires Task 1's `OptionContract`.

## Acceptance Criteria
- [ ] Options data client: fetch chain snapshots (`GET /v1beta1/options/snapshots/{underlying}` — greeks + IV per contract, with type/strike/expiry/feed filters) and resolve tradable contracts (`GET /v2/options/contracts` by underlying/expiry/strike/type → OCC `symbol`, `tradable`).
- [ ] OCC symbol construction + parse helpers (21-char format, round-trips with the contracts endpoint).
- [ ] `PlaceOrder` handles `SecType=="OPT"`: posts to `/v2/orders` with the OCC `symbol`, contract qty, `type:"limit"`, `limit_price`, `time_in_force`; no bracket/OCO attempted (Alpaca rejects it).
- [ ] `GetPositions` reads and emits option positions (`asset_class:"us_option"`) with contract identity + multiplier populated.
- [ ] Reads the real-time OPRA feed when configured; degrades explicitly (logs) rather than silently using the 15-min-delayed indicative feed.
- [ ] Handles null greeks/IV gracefully (returns "unavailable", never a zero that a gate could misread).
- [ ] Tests against `httptest` fixtures for chain, contracts, order, positions.

## Technical Details
- Adapter: `internal/execution/alpaca_broker.go` — `PlaceOrder` (:46-98), `GetPositions` (:181-228); reuse `do`/auth.
- Template: `internal/execution/ibkr_broker.go:67-82` (secType branching, order JSON stamping).
- Feeds: free=indicative(15-min delay); Algo Trader Plus=OPRA real-time. Real-time required for live (see Task 9 config for the feed selector/secret).
- Symbol example: `AAPL240223C00095000` = AAPL 2024-02-23 Call $95.00.
