# Task: Options reconciler + scope-out

## Description

Keep option positions honest against Alpaca truth — the recurring failure class in this codebase. Build ONE new OCC-keyed reconciler and scope the nine existing ticker-keyed matchers OUT of option positions (they can't resolve OCC symbols and would false-alarm). This mirrors the existing forex-only scoping precedent and keeps all options complexity in one place with zero regression risk to the proven reconcilers.

## Acceptance Criteria
- [ ] New options reconciler matches Alpaca option positions (`asset_class:"us_option"`, OCC symbol) to `orb_trades` rows by OCC symbol, with an OCC→underlying reverse map.
- [ ] Orphan detection: any broker option position with no explaining filled DB row raises an alert (detection parity with existing orphan detectors; detection-only, no auto-placement).
- [ ] Each of the nine existing matchers gains an `asset_class != 'option'` (or option-symbol-shape) guard so it ignores option positions:
  - `reconcileBrokerVsDB` (`internal/engine/reconcile.go:150-179`)
  - `AdoptBrokerOrphans` (`reconcile.go:308-356`)
  - `findOrphanedPositions` (`internal/orb/orphan_detector.go:136-176`)
  - `matchOrphanEntries` (`internal/orb/fill_reconcile.go:104-130`)
  - `cancelStaleOCOLegs` (`fill_reconcile.go:48-58`)
  - split-entry orphan sweep (`internal/orb/split_orphan.go:32-88`)
  - exit reconcile (`internal/engine/exit_reconcile.go`)
  - statement reconcile (`cmd/orb-reconcile-statement/main.go`)
  - broker-verify (`cmd/broker-verify/main.go`)
- [ ] Zero-regression: existing forex/futures/equity reconciliation behavior unchanged (guarded tests).
- [ ] Tests: OCC match, OCC→underlying reverse map, orphan alert, and each guard skipping an option position.

## Technical Details
- Precedent: the "forex-only" scoping already in `orphan_detector.go:41-51,104-119` and `fill_reconcile.go:74` — same shape, driven by `asset_class` this time.
- Discriminator is robust: Alpaca tags option positions `asset_class:"us_option"`, and OCC symbols are unambiguous 21-char.
- The new reconciler must be lifecycle-aware (filled option with a working close order vs. closed) — this complexity is exactly why it's isolated here rather than spread across nine matchers.
